# YouTube Manager 🎬

A simple **Python-based YouTube Manager** application that allows users to manage YouTube video information through a command-line interface.

## 🚀 Features

* Add YouTube videos
* View all saved videos
* Update video information
* Delete videos
* Store video data using SQLite
* Simple command-line interface

## 🛠️ Technologies Used

* Python
* SQLite
* SQL
* Command Line Interface (CLI)

## 📂 Project Structure

```text
youtube_manager/
│
├── youtube_manager.py
├── youtube_manager.db
└── README.md
```

## ▶️ How to Run

Make sure Python is installed on your system.

```bash
python youtube_manager.py
```

## 🎯 Purpose

This project was created to practice Python programming, database operations, CRUD functionality, and working with SQLite.
